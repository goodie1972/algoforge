# 2026-06-02 修改记录

## 1. RSI 策略亏损改进 — EMA20 趋势斜率过滤

**背景**: 6月1日 RSI Bollinger 策略（H1）连续亏损 6 张 BUY，根源是无趋势过滤 + 无冷却。

### 改动:

| 文件 | 改动 |
|------|------|
| `strategies/rsi_bollinger.py` | `_calc_ema()` 增加 `shift` 参数；`generate_signal()` 增加 EMA20 趋势方向过滤 — BUY 仅限 EMA20 上行，SELL 仅限 EMA20 下行 |
| `strategies/stoch_bollinger.py` | 同上（EMA20 趋势过滤） |

**效果**: 下行趋势中价格触碰下轨不再盲目开多，等待 EMA20 确认拐头。

## 2. 新增引擎层风控

### 2a. 单策略绝对亏损上限

| 文件 | 改动 |
|------|------|
| `config/settings.py` | 新增 `PER_STRATEGY_REALIZED_LOSS_AMOUNT = 30.0` |
| `main.py` | `StrategyRiskState` 新增 `realized_loss_amount_blocked`, `realized_loss_amount_blocked_at`；`_record_close()` 检查累计亏损 ≥$30 触发 12h 冷却；`_is_strategy_blocked()` 增加对应检查和自动解锁 |

**逻辑**: 与百分比亏损（5%）并行，任一触发即阻断。亏损回正后自动解除。

### 2b. 连续亏损冷却

| 文件 | 改动 |
|------|------|
| `config/settings.py` | 新增 `MAX_CONSECUTIVE_LOSSES = 3`, `CONSECUTIVE_LOSS_COOLDOWN_HOURS = 4` |
| `main.py` | `StrategyRiskState` 新增 `consecutive_losses`, `consecutive_loss_blocked`, `consecutive_loss_blocked_at`；`_record_close()` — 亏损递增/盈利归零；触发 ≥3 次连续亏损 → 4h 冷却 |

**逻辑**: 与绝对亏损上限并行，各自独立阻断。
