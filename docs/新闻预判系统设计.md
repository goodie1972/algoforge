# News-Bias 新闻预判报告系统设计

## Context

每天 8:00 和 20:00（北京时间，交易日）生成新闻预判报告，含：
1. 从多个新闻源抓取 XAUUSD 相关新闻
2. 按五大影响变量分类，写逻辑链分析
3. 综合给出 12 小时预判（涨/跌/震荡）
4. Dashboard 弹窗展示 + 新闻评估独立模块
5. 12 小时后自动验证

核心：使用"逻辑链模型"而非简单利多/利空标签。
黄金传导链：新闻 → 影响变量X → 实际利率/美元/降息预期 → 金价

## 一、五大影响变量与逻辑链

```
1. 通胀类（权重最高）
   通胀超预期 → 加息预期↑ → 实际利率↑ → 美元↑ → 金价↓
   通胀回落 → 加息预期↓ → 实际利率↓ → 美元↓ → 金价↑
   注意：通胀高≠金价涨，相反当前是"通胀→紧缩→金价跌"负反馈

2. 央行利率/政策类
   鹰派(FOMC/讲话) → 降息预期↓ → 实际利率↑ → 金价↓
   鸽派 → 降息预期↑ → 实际利率↓ → 金价↑

3. 地缘政治（双刃剑）
   地缘紧张 → 油价↑ → 通胀↑ → 加息↑ → 金价↓（2026 新版逻辑）
   和平协议 → 油价↓ → 通胀↓ → 加息↓ → 金价↑
   关键：看影响"避险"还是"通胀"

4. 美元/美债收益率（最直接定价）
   美元↓/收益率↓ → 持有成本↓ → 金价↑
   美元↑/收益率↑ → 持有成本↑ → 金价↓

5. 央行购金/ETF 资金流（中长线）
   央行购金 → 长线买盘 → 金价支撑↑
   ETF 流出 → 短线抛压 → 金价压力↓
```

## 三、预测生成逻辑

### `services/news_bias.py` 新增方法

`generate_prediction_report() → dict`:

```
Step 1: 抓新闻
  - NewsFetcher.fetch_news() → 获取各源新闻
  - 按变量分类 (inflation/rates/geopolitical/usd/cb_buying)

Step 2: 逐条评估
  对每条新闻问三个问题：
  ① 影响哪个变量？
  ② 正向还是负向作用于金价？
  ③ 多变量共振还是对冲？

Step 3: 变量加权汇总
  - 通胀类权重 0.30
  - 利率政策 0.25
  - 地缘政治 0.20
  - 美元/收益率 0.15
  - 供需资金 0.10
  
  每类下面：∑(方向 × 权重) → 该类净偏向
  
Step 4: 结合技术面
  - RSI > 70 或 < 30 → 加减分
  - H1 趋势方向 → 加减分
  - 当前价格在 BB 的位置

Step 5: 综合预判
  加权总分 > +0.3 → 看涨
  加权总分 < -0.3 → 看跌
  其余 → 震荡
```

## 四、数据模型

### `data/database.py` — 新增 `news_bias_reports` 表

```sql
CREATE TABLE IF NOT EXISTS news_bias_reports (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    title TEXT NOT NULL,
    news_items TEXT DEFAULT '[]',         -- JSON: 按变量分类的新闻
    variable_scores TEXT DEFAULT '{}',    -- JSON: 五大变量各自得分
    market_context TEXT DEFAULT '{}',     -- JSON: price, rsi, trend, bb_position
    prediction TEXT DEFAULT '{}',         -- JSON: {direction, reason, confidence, score}
    entry_price REAL DEFAULT 0,
    verify_price REAL DEFAULT 0,
    verify_result TEXT DEFAULT '',        -- 'correct' | 'wrong' | 'pending'
    verify_at TEXT DEFAULT '',
    popped_up INTEGER DEFAULT 0,
    summary TEXT DEFAULT '',
    created_at TEXT DEFAULT (datetime('now'))
);
```

CRUD:
- `insert_news_bias_report(record) → id`
- `get_news_bias_reports(date, page, page_size) → list`
- `get_news_bias_report(id) → dict`
- `update_news_bias_report(id, updates) → bool`
- `get_unverified_reports() → list`
- `get_latest_news_bias_report() → dict`

## 五、调度

### `dashboard/backend/main.py` — 新增 `news_bias_loop()`

只在交易日（周一到周五）执行：

```python
async def news_bias_loop():
    """每天 8:00 和 20:00 北京时生成预判报告 + 弹窗"""
    await asyncio.sleep(60)
    while PollerState.running:
        now = datetime.now()
        # 非交易日跳过
        if now.weekday() >= 5:  # 周六日
            await asyncio.sleep(3600)
            continue
        
        target_hours = [8, 20]
        current_hour = now.hour
        current_min = now.minute
        
        if current_hour in target_hours and current_min < 5:
            # 到点了，生成报告
            evaluator = NewsBiasEvaluator()
            evaluator.verify_old_predictions()
            report = evaluator.generate_prediction_report()
            if report:
                await ws_manager.broadcast("news_bias_popup", report)
        
        # 计算到下一个目标时间的秒数
        next_run = calc_next_run(target_hours, now)
        await asyncio.sleep(min(next_run, 3600))
```

注册在 lifespan 的 tasks 列表中。
