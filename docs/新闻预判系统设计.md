## 数据源

### 主数据源：汇通网 7×24 黄金快讯
- **URL**: `https://kx.fx678.com/`
- **抓取方式**: HTTP GET，解析 HTML 快讯列表
- **更新频率**: 每 4 小时
- **内容**: 黄金相关快讯（含标题、时间、正文）

### 辅助数据源：金十数据
- **URL**: `https://www.jin10.com/`
- **抓取方式**: HTTP GET，解析页面内嵌 JSON 数据
- **内容**: 实时财经快讯，需过滤黄金相关关键词
- **用途**: 与汇通数据交叉验证

### 经济日历
- **URL**: `https://www.forexfactory.com/calendar`
- **抓取方式**: HTTP GET 获取 JSON 数据（通过 `nfs.faireconomy.media`）
- **内容**: 经济事件（NFP/CPI/利率决议等），含前值/预测/实际值
- **用途**: 前端跑马灯展示，不参与方向判断

## LLM 方向判断

### 工作流程
1. `judge_with_llm()` 接收快讯列表
2. 根据活跃 LLM Provider 构建 prompt
3. 要求 LLM 同时输出：方向（利多/利空/中性）+ 置信度 + 英文翻译
4. 解析 LLM 返回，存入 `gold_news` 表（含 `content_en` 字段）
5. LLM 调用失败时自动回退到关键词规则判断

### LLM Provider 管理
- **文件**: `services/llm_provider.py`
- **配置**: 支持多 Provider（OpenAI 兼容接口），在 Dashboard AI Agent 页面管理
- **存储**: `data/llm_providers.json`（在 `.gitignore` 中，不提交 git）
- **回退方案**: 环境变量 `LLM_API_KEY` / `LLM_BASE_URL` / `LLM_MODEL`

### 方向判断标准
| 方向 | 说明 | 示例事件 |
|:----|:------|:---------|
| 利多 (bullish) | 利好黄金价格上涨 | 地缘紧张、美元走弱、降息预期、就业数据意外走弱 |
| 利空 (bearish) | 利空黄金价格下跌 | 美元走强、加息预期、就业数据强劲、停火协议 |
| 中性 (neutral) | 对黄金价格影响不明 | 常规经济数据公布、技术性调整 |

## 数据库

### gold_news 表
```sql
CREATE TABLE gold_news (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    source TEXT NOT NULL,          -- 'huicong' / 'jin10'
    content TEXT NOT NULL,         -- 快讯原文
    content_en TEXT DEFAULT '',    -- LLM 英文翻译
    direction TEXT DEFAULT 'neutral',  -- bullish / bearish / neutral
    direction_reason TEXT DEFAULT '',   -- 判断理由
    direction_confidence TEXT DEFAULT 'low',  -- high / medium / low
    news_time TEXT DEFAULT '',          -- 快讯时间
    fetched_at REAL NOT NULL,           -- 抓取时间戳
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP
);
```

## 前端展示

### 跑马灯（经济日历）
- **位置**: AppShell 顶部栏，与版本号同一水平
- **内容**: 最近 5 个经济事件滚动展示（日期/时间/名称/前值/预测）
- **交互**: 点击弹出 Modal（75%×75%），显示完整事件列表
- **速度**: 40 秒滚动周期

### 黄金快讯面板
- **位置**: Dashboard 右侧 StrategySignals 下方
- **内容**: 最近 5 条黄金快讯，每条显示方向标签（绿=利多/红=利空/灰=中性）
- **交互**: 放大按钮 → 居中 Modal（75%×75%），字体 18px
- **数据**: 通过 `/api/news/gold` 获取

## 准确性评估

- 每次抓取后，对 1 小时前的快讯做复盘
- 对比判断方向与 15 分钟/1 小时后的实际价格走势
- 统计准确率，存入 `gold_news` 表的 `evaluated_at`/`actual_move_15m`/`actual_move_1h` 字段
- 通过 `/api/news/gold` 返回评估摘要

## API 端点

| 端点 | 说明 | 返回 |
|:----|:------|:-----|
| `GET /api/news/gold` | 黄金快讯 + 偏向评估 | 快讯列表、摘要统计、当前偏向 |
| `GET /api/news/calendar` | 经济日历事件 | 本周事件列表 |
