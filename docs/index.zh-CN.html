Features

核心特性

从数据采集到策略执行，从风控到监控，全链路覆盖

⚡

多策略并行

25+ 个策略同时运行，独立 Magic Number 和风控状态。自动扫描 strategies/ 目录发现新策略，零配置注册。

🏗️

三轨架构

DataFactory（数据采集+指标计算）→ 策略员（信号评分）→ Athlete（tick 验证开仓），三层分离，职责清晰。

🛡️

完整风控

利润回撤止盈 + ATR 移动止盈 + ATR 硬止损。GateManager / RiskManager / TradeManager 三层防护体系。

📊

数据驱动

DataFactory 统一计算 26 个 TA-Lib 指标，F043 MT4 值优先，跨策略共享缓存，零冗余计算。

📝

纸面测试

信号全量模拟入场 + 出场，按策略规则模拟平仓，真实成交价计算盈亏，策略上线前充分验证。

🔄

自修复监控

5 分钟自动检查引擎状态，崩溃 / 桥接断连自动重启，实时 WebSocket 推送，日志全量追踪。

Architecture

系统架构

MT4 + Python 引擎 + Vue 前端，三轨分离，职责清晰

│              MT4 + FreeMT4Bridge EA  (TCP Socket :23232)           │
└────────────────────────────┬─────────────────────────────────────┘
                             │
┌────────────────────────────▼─────────────────────────────────────┐
│                     core/bridge.py                                   │

└────────────────────────────┬─────────────────────────────────────┘
                             │
┌────────────────────────────▼─────────────────────────────────────┐
│                    TradingEngine (三轨架构)                          │

│  │ 轨1: DataFactory (独立线程)                              │   │
│  │     → 增量拉取 K 线 → 26 个 TA-Lib 指标统一计算              │   │
│  │     → F043 MT4 值优先，本地计算回退                          │   │
│  ├───────────────────────────────────────────────────────────┤   │
│  │ 轨2: 策略员 (主循环)                                      │   │
│  │     → get_indicator() 读缓存 → 评分出门票                   │   │
│  │     → 25+ 策略并行，独立风控状态                            │   │
│  ├───────────────────────────────────────────────────────────┤   │
│  │ 轨3: Athlete (tick 验证层)                               │   │
│  │     → _verify_entry 实时重算入场条件 → 10 秒过期作废         │   │
│  │     → 三层退出：利润回撤止盈 / ATR 移动止盈 / ATR 硬止损    │   │

│  │ SQLite 数据库         │  │  实时信号 / 持仓 / 策略管理     │  │
