# Gold Auto Research H1 共识策略 (gold_auto_research)

## 概述

- **策略名称：** `gold_auto_research`
- **类名：** `GoldAutoResearchStrategy`
- **Magic Number：** `880306`
- **运行周期：** H1（1 小时）
- **策略类型：** 共识投票策略
- **设计目标：** 四个独立维度各自判断市场方向，全部一致时才触发信号

## 设计理念

与其他基于评分累加的策略不同，本策略采用**共识投票机制**——四个维度中的每个维度独立判断方向，只有全部达成一致时才入场。

```
入场条件 = 趋势方向一致
         AND 动量方向一致
         AND 波动率激活
         AND 安全无警示
```

这四种维度覆盖了市场分析的核心要素：方向（趋势）、力度（动量）、环境（波动率）、风险（安全性）。任何一个维度的反对都足以阻止交易。

这种方式牺牲了交易频率，但换取了更高的信号质量。

## 指标参数

| 参数 | 值 | 说明 |
|------|-----|------|
| 趋势均线 | EMA10, EMA20 | 判断趋势方向 |

| 随机指标 | 14/3/3 | 动量确认 |

| ATR 周期 | 14 | 波动率计算 |
| ATR SMA 周期 | 20 | ATR 比较基准 |

## 入场逻辑 — 4 因子共识 + H4 趋势门禁

### H4 趋势门禁（顶层硬规则）

在 4 因子共识之前，先加载 H4 K 线（从 SQLite）计算 SMA50 趋势：

- **H4 = DOWN**：H1 趋势即使翻多也**禁 BUY**（防下跌中的反弹诱多）
- **H4 = UP**：H1 趋势即使翻空也**禁 SELL**（防上涨中的回调诱空）

> 这修正了 EMA10/20 在 H1 周期上容易被反弹扭曲的问题。
> 昨天的 -$64 大亏单（BUY 4046→3981）就是 H4=DOWN 时 H1 反弹翻多导致的。

### 因子 1：趋势 (EMA10/20)

判断价格运动的基本方向。

```
trend_up = EMA10 > EMA20（上升趋势）
trend_dn = EMA10 < EMA20（下降趋势）
```

EMA10（快线）与 EMA20（慢线）的相对位置关系判断趋势，比价格与均线的关系更稳定。

### 因子 2：动量 (MACD + 随机指标)

确认趋势是否有足够的推动力。

```
动量向上 = MACD 线 > 信号线  或  %K > %D
动量向下 = MACD 线 < 信号线  或  %K < %D
```

两个指标二选一即可——MACD 判断中期动量，随机指标判断短期动量，任一支持即认可。

### 因子 3：波动率活性 (ADX + ATR)

确保市场处于活跃状态。不活跃的市场中，即使方向判断正确也可能无法产生有效行情。

```
波动率活跃 = ADX(14) > 20   或  当前 ATR > ATR_SMA(20)
```

ADX > 20 表示趋势有强度；ATR 上升表示波动率在扩张。两者满足其一即认可。

**重要：如果市场不活跃（vol_active = False），则不会产生任何信号。**

#### ADX 计算说明

策略独立实现完整 ADX(14) 计算：

1. 计算 +DM 和 -DM（方向性运动）
2. 分别平滑为 +DI 和 -DI（占 ATR 百分比）
3. DX = |+DI - -DI| / (+DI + -DI) × 100
4. ADX = DX 的 RMA（滚动移动平均）

ADX 值缓存在 `_cached_adx` 中，按已计算的 K 线数量键控。

### 因子 4：安全性 (RSI + 布林带)

防止在趋势耗尽点入场——在价格已经极度延伸时拒绝信号。

```
多头安全 = 不满足（价格 ≥ BB 上轨 AND RSI ≥ 70）
空头安全 = 不满足（价格 ≤ BB 下轨 AND RSI ≤ 30）
```

当价格触及布林带外侧且 RSI 显示极端值时，认为该方向不安全——即使前三个因子都看多，也不会入场。

### 信号决策

```
BUY  = trend_up AND mom_up AND vol_active AND safe_up AND H4 ≠ DOWN
SELL = trend_dn AND mom_dn AND vol_active AND safe_dn AND H4 ≠ UP
```

**四个条件必须全部满足 + H4 趋势不矛盾。没有评分、没有加权、没有折中。**

## 出场逻辑

三层退出机制，同标准实现。

**趋势判断（出场乘数）：** 使用 EMA10 vs EMA20 判断趋势方向

**盈利/亏损分离：** 同标准逻辑

## 数据需求

- H1 K 线（自身周期）
- 最小数据量：100 根 H1 K 线

## 初始止损/止盈

- **止损：** ATR × hard_mult（趋势感知）
- **止盈：** 远置

## 风险参数

| 参数 | 值 |
|------|-----|
| 最大持仓 | 1 |
| 首选手数 | 0.01 |
| 双倍首单 | 否 |
| 新闻收紧 | 支持 |

## 保本出场局限

与所有策略共享基类 `_check_breakeven_exit()`，MFE≥0.3ATR 后回成本±0.05ATR 平仓。

在 RSI 接近安全阈值边缘（RSI≤35 或 RSI≥70 附近）时开仓，价格处于布林带附近，反弹动力强，易在开仓后 10-20 分钟内被保本出场。

## 优劣势

**优势：**
- 共识机制确保信号质量极高，减少假信号
- 四个维度互不重叠，覆盖方向→力度→环境→风险的全链条
- ADX/ATR 活性过滤防止横盘行情中的无效交易
- RSI+BB 安全机制防止追高/杀跌
- 不需要外部数据源（无需 SQLite）**仅 H4 趋势门禁需要 SQLite**

**局限：**
- 较保守，交易频率最低（四个条件同时满足的概率较低）
- 在 ADX < 20 的低波动市场中可能长时间无信号
- EMA10/20 对趋势变化的反应速度不如 EMA9/21
- 在快速反转行情中可能因安全因子而错过入场点
