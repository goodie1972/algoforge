# Stoch Trend M30

**类型：** 自研 | **周期：** M30 | **Magic：** 660903 | **版本：** v3

## 策略描述

Stoch 均值回归 + 趋势叠加（T6v8 三模）。根据市场状态自动切换三种进场模式：

1. **窄幅震荡（ADX < 28 + BB width ≤ 2%）** — 原版 Stoch K/D 交叉 + EMA21 均值回归
2. **宽幅震荡（ADX < 28 + BB width > 2%）** — BB 触轨 + K 极端 + DI 交叉确认反转
3. **趋势（ADX ≥ 28）** — DI 优势方向 + EMA21 + Stoch 交叉顺势

BB 宽度 2% 阈值基于黄金分割 61.8% 分位统计，自动适配当前波动环境。

## 入场规则

### 窄幅震荡

| 方向 | 条件 |
|------|------|
| BUY | K < 20 + K 上穿 D + close < EMA21 |
| SELL | K > 80 + K 下穿 D + close > EMA21 |

### 宽幅震荡

| 方向 | 条件 |
|------|------|
| BUY | low ≤ BB 下轨 + K < 15 + DI 金叉（+DI 上穿 -DI） |
| SELL | high ≥ BB 上轨 + K > 85 + DI 死叉（+DI 下穿 -DI） |

### 趋势

| 方向 | 条件 |
|------|------|
| BUY | +DI - -DI > 10 + close > EMA21 + K 上穿 D |
| SELL | -DI - +DI > 10 + close < EMA21 + K 下穿 D |

## 出场规则

| 模式 | 条件 | 说明 |
|------|------|------|
| 震荡硬止损 | SL = 1.0 × ATR | 宽幅/窄幅同规则 |
| 趋势硬止损 | SL = 2.0 × ATR | — |
| 趋势止盈 | TP = 4.0 × ATR | — |
| 趋势回撤 | 峰值回撤 2.0 × ATR | trail_dist = TP/2 |
| ADX 衰减 | ADX < 20 | 趋势可能结束 |
| DI 反转 | +DI/-DI 交叉反向 | 趋势方向改变 |
| 震荡出场 | K/D 反向交叉 + close ≥ EMA21 | K≥80(多)/K≤20(空)直接出，BB 方向不一致也出 |

## 参数

| 参数 | 值 | 说明 |
|------|-----|------|
| ma_period | 21 | EMA 周期 |
| adx_range_threshold | 28 | ADX < 28 为震荡，≥ 28 为趋势 |
| bb_width_threshold | 0.02 (2%) | 宽窄幅分界 |
| di_threshold | 10 | 趋势模式 DI 优势门槛 |
| trend_sl_atr | 2.0 | 趋势模式 SL 倍数 |
| trend_tp_atr | 4.0 | 趋势模式 TP 倍数 |
