# M30 RSI + 布林带均值回归策略 (M30_rsi_bb)

## 概述

- **策略名称：** `M30_rsi_bb`
- **类名：** `M30RSIStrategy`
- **Magic Number：** `660706`
- **运行周期：** M30（30 分钟）
- **策略类型：** 均值回归
- **设计目标：** 捕捉 M30 周期上因过度延伸而产生的价格回归机会，结合 H1 大趋势方向过滤

## 设计理念

该策略基于均值回归理论——当价格过度偏离均值时会回归。使用布林带识别价格极端位置，RSI 确认超买超卖状态，并用 H1 SMA200 趋势过滤确保只顺着大方向交易。

与纯趋势策略不同，均值回归策略在震荡市场中表现更佳，但在强单边趋势中可能逆势。因此引入 H1 趋势门控来管理这一风险。

## 指标参数

| 参数 | 值 | 说明 |
|------|-----|------|
| RSI 周期 | 14 | 标准 RSI 计算周期 |
| RSI 超卖阈值 | 30 | RSI 低于此值视为超卖 |
| RSI 超买阈值 | 65 | RSI 高于此值视为超买 |
| 布林带周期 | 20 | 中轨为 SMA20 |
| 布林带标准差 | 2.0 | 上下轨宽度 |
| ATR 周期 | 20 | 波动率计算周期 |
| 评分阈值 | 3 | 触发信号所需最低分数 |

## 入场逻辑 — 5 因子评分

系统评估 5 个因子，每个因子为多头或空头贡献分数。总分 ≥ 3 且 H1 趋势对齐时才触发信号。

### 多头信号

> 条件：`long_score >= 3` **且** `H1_trend == 'UP'`

| 因子 | 条件 | 分数 | 说明 |
|------|------|------|------|
| ① H1 趋势 | H1 收盘价 > SMA200 | +1 | 大趋势向上 |
| ② 布林带触碰 | 收盘价 ≤ 下轨 | +1 | 价格触及下轨 |
| ③ RSI 超卖 | RSI < 30 | +1 | 确认超卖 |
| ④ RSI 方向 | RSI 最近 2 根 K 线上升 | +1 | 短期动量转向 |
| ⑤ 低波动率 | ATR < 均价 × 2.5% | +1 | 低波动回归概率高 |

### 空头信号

> 条件：`short_score >= 3` **且** `H1_trend == 'DOWN'`

| 因子 | 条件 | 分数 |
|------|------|------|
| ① H1 趋势 | H1 收盘价 < SMA200 | +1 |
| ② 布林带触碰 | 收盘价 ≥ 上轨 | +1 |
| ③ RSI 超买 | RSI > 65 | +1 |
| ④ RSI 方向 | RSI 最近 2 根 K 线下降 | +1 |
| ⑤ 低波动率 | ATR < 均价 × 2.5% | +1 |

### 趋势门控

H1 趋势通过 SMA200 判断，是整个信号系统的门控条件：

- **H1 趋势 = UP：** 只允许开多头，不开空头
- **H1 趋势 = DOWN：** 只允许开空头，不开多头
- **H1 趋势 = NEUTRAL：** 不开仓（SMA200 无有效值）

> 即使 `long_score = 5`（满分），如果 H1 趋势为 DOWN，也不会触发多头信号。反之亦然。

## 出场逻辑 — 三层退出

与所有策略共享相同退出机制 `check_ema20_exit()`，但出场乘数根据趋势方向动态调整。

### 利润回撤止盈

当持仓已有明显利润（> ATR × 0.5），如果利润从峰值回撤超过 25%，则平仓离场。

```
当前利润 / 峰值利润 < 0.75  →  止盈离场
```

### ATR 移动止盈

跟踪持仓期间的价格极值（多头的最高价、空头的最低价），当价格从极值反向运行超过 ATR × trail_mult 时离场。

```
多头：最高价 - 当前卖价 > ATR × trail_mult
空头：当前买价 - 最低价 > ATR × trail_mult
```

### ATR 硬止损

当亏损达到 ATR × hard_mult 时强制离场。

```
多头：开仓价 - 当前卖价 > ATR × hard_mult
空头：当前买价 - 开仓价 > ATR × hard_mult
```

### 趋势感知出场乘数

| H1 趋势 | 方向 | trail_mult | hard_mult |
|---------|------|-----------|-----------|
| UP | 做多（顺势） | 2.5 | 4.0 |
| UP | 做空（逆势） | 1.0 | 2.0 |
| DOWN | 做空（顺势） | 2.5 | 4.0 |
| DOWN | 做多（逆势） | 1.0 | 2.0 |
| NEUTRAL | 任意 | 1.5 | 3.0 |

**核心思想：** 顺势仓位给更宽松的出场空间（trail=2.5, hard=4.0），让利润奔跑；逆势仓位收紧（trail=1.0, hard=2.0），及时止损。

### 盈利/亏损分离逻辑

```
if current_profit > 0:
    使用：利润回撤止盈 + ATR 移动止盈 + ATR 硬止损（全部启用）
else:
    仅使用：ATR 硬止损（不启用任何移动止盈，防止被震荡出局）
```

## 数据依赖

- M30 K 线（自身周期）
- H1 K 线（从 SQLite 获取 SMA200 判断趋势）
- 最小数据量：100 根 M30 K 线，200 根 H1 K 线

## 初始止损/止盈

- **止损：** ATR × hard_mult（趋势感知，同出场乘数）
- **止盈：** 止损 × 50（远置止盈，让三层退出机制管理出场）

## 风险参数

| 参数 | 值 | 说明 |
|------|-----|------|
| 最大持仓 | 1 | 同时最多 1 单 |
| 首选手数 | 0.01 | 标准手数 |
| 双倍首单 | 否 | 不启用 |
| 新闻收紧 | 支持 | trail=0.5, hard=1.0, drawdown=15% |

## 优劣势

**优势：**
- 在震荡和回调行情中表现稳定
- H1 趋势门控防止逆势交易
- 趋势感知出场乘数合理匹配不同市场状态

**局限：**
- 在强单边趋势中信号较少（价格持续偏离均值）
- 需要 H1 SMA200 数据，依赖 SQLite 数据库
- 均线回归策略在趋势加速行情中可能过早离场
