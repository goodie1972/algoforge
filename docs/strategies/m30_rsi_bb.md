# M30 RSI + 布林带均值回归策略 (M30_rsi_bb)

## 概述

- **策略名称：** `M30_rsi_bb`
- **类名：** `M30RSIStrategy`
- **Magic Number：** `660707`（当前主版本） / `660705, 660706`（旧版，自动接管持仓）
- **运行周期：** M30（30 分钟）
- **策略类型：** 均值回归 + 趋势门禁
- **设计目标：** 捕捉 M30 周期上的均值回归机会，用 H1 MA20 趋势门禁防止逆势交易

## 设计理念

均值回归策略——当价格过度偏离均值时会回归。使用布林带识别价格极端位置，RSI 确认超买超卖状态，成交量/K线形态辅助确认。

核心改进（v12）：**H1 MA20 趋势门禁**替代了旧的 ADX>28 门禁。H1=DOWN 时强制禁做多，H1=UP 时强制禁做空，彻底防止在大趋势方向上的逆势交易。

## 入场逻辑 — 7 因子评分

### 评分因子

| # | 因子 | 多头 | 空头 |
|---|------|------|------|
| ① | M30 趋势 (close vs MA14) | MA14-UP +1 | MA14-DN +1 |
| ② | BB 位置 (进入上下轨10%区间) | ≤下轨10% +1 | ≥上轨10% +1 |
| ③ | RSI 分层评分 | <25 **+2**；25~35 +1 | >75 **+2**；65~75 +1 |
| ④ | M30 RSI 方向 (连续3根递升/递降) | RSI-UP +1 | RSI-DN +1 |
| ⑤ | DI 强度 (\|DI差\|>10) | DI+ >10 +1 | DI- >10 +1 |
| ⑥ | 成交量 (>SMA20×1.3 + 同向K线) | VOL↑ +1 | VOL↓ +1 |
| ⑦ | K线形态 (TA-Lib强反转) | 晨星/锤子/刺透 +1 | 暮星/射击/乌云/吞没/吊人 +1 |

### 决策规则

```
总分 ≥ 4        → 直接开仓（LONG或SELL）
总分 = 3        → 需 diff ≥ 2 才开（long_score - short_score ≥ 2）
long_score ≤ 0  → 不开多（被 H1 门禁清零）
short_score ≤ 0 → 不开空（被 H1 门禁清零）
```

### H1 趋势门禁（第⑥步，因子评分后执行）

```
加载 H1 K 线 → 计算 H1 MA20 趋势
H1 = DOWN → long_score 清零（禁所有 BUY 信号）
H1 = UP   → short_score 清零（禁所有 SELL 信号）
H1 = NEUTRAL（数据不足）→ 不做任何拦截
```

> 门禁只拦截反向信号，**不**给同向信号加分。即使 long_score=7（满分），H1=DOWN 时依然禁 BUY。
> 冷却信息（COOLDOWN）保留不被清零。

## 出场逻辑

### Broker SL/TP（订单级硬边界）

| 场景 | SL (×ATR) | TP (×ATR) |
|------|:---------:|:---------:|
| 顺趋势（与 MA14 同向） | 2.5 | 4.0 |
| 逆趋势（与 MA14 反向） | 1.0 | 2.0 |
| 震荡（MA14=NEUTRAL） | 1.5 | 3.0 |

### 运行时三重退出

| 机制 | 条件 | 说明 |
|------|------|------|
| 保本出场 | MFE≥0.3ATR→回成本±0.05ATR | 防盈利变亏损 |
| 利润回撤止盈 | 峰值利润回撤 > 25%（ADX>25→50%） | 需峰值≥0.5ATR |
| ATR 追踪止盈 | 从极值反向 > trail_mult×ATR | trail_mult 开仓时锁定：顺1.5/逆1.0/震荡1.2 |
| DI 跳过 | 盈利且 +DI−-DI > 10（BUY）或 -DI−+DI > 10（SELL） | 强趋势中跳过追踪止盈 |
| 硬止损 | 亏损 > hard_mult×ATR | hard_mult 开仓时锁定：顺3.0/逆2.0/震荡2.5 |

> 盈利阶段：利润回撤 + ATR 追踪 + DI 跳过 + 硬止损（全部启用）
> 亏损阶段：仅硬止损（不启用追踪，防被震荡出局）

## 保本出场局限

基类统一 `_check_breakeven_exit()`：MFE≥0.3ATR 后回成本±0.05ATR 平仓。

**实盘中发现的问题**：当 RSI 处于深度超卖（<25）或深度超买（>75）时开仓，价格已处于极端位置。开仓后往往先走一段有利行情（达标保本触发条件①），但极端位置本身就有强反弹动力，价格弹回成本后保本出场（条件②），导致持仓仅 10-20 分钟就被微亏出场。

**典型场景**（2026-07-01 06:56）：
```
SELL @ 3976.16  RSI=27.3  BB下方(price_pos=-0.13)
→ 先跌几美元（MFE达标）
→ 快速弹回成本（保本触发）
→ 17分钟后平仓，亏 $0.22
```
方向判断正确（H1=DOWN），但保本过于敏感，没给趋势单足够的奔跑空间。

## 优劣势

**优势：**
- 7 因子多维度评分，信号质量高
- H1 趋势门禁彻底根除逆势交易（昨天 $37 亏单的根本原因）
- RSI 分层评分（浅/深两档）更精准

**局限：**
- 依赖 SQLite 数据库中的 H1 K 线数据
- 日均信号少（仅在大趋势回调至极端位置时触发）
- 无订单级别的隔夜强制平仓逻辑
- **保本出场在极端位置开仓时过于主动**：RSI<30 深度区开仓后反弹动力强，易触发保本过早出场
