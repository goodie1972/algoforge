# 版本更新检查 — 红点改为"远程有新版本" + 一键更新

## Context

右上角的版本 badge 当前用红点表示"git 工作区有未提交修改"，这对使用者没有意义。使用者关心的是：**当前版本是不是最新的？需不需要更新？**

改造目标：借鉴 Warp 的更新机制——版本 badge 自动检查 GitHub 远程是否有新版本，有则红点提示，点击可查看更新内容并一键拉取。

---

## 设计

### 后端改动

#### `core/version.py` 新增 `check_remote_update()`

```python
def check_remote_update() -> dict:
    """检查远程是否有新版本"""
    behind = _git("rev-list", "--count", "HEAD..origin/main")
    return {
        "has_update": behind.isdigit() and int(behind) > 0,
        "behind_count": int(behind) if behind.isdigit() else 0,
    }
```

- `git fetch origin` 在后台静默更新 remote refs（不改变工作区）
- `git rev-list --count HEAD..origin/main` 返回落后 remote 的 commit 数

#### `GET /api/version` 扩展返回

现有 `get_version_info()` 增加字段：
```python
{
    "version": "0.7.8",
    "commit": "abc1234",
    "branch": "main",
    "dirty": False,
    "display": "v0.7.8 (abc1234)",
    "has_update": True,        # ← 新增
    "behind_count": 5,         # ← 新增
}
```

#### 新增 `GET /api/version/remote-changelog`

返回 HEAD..origin/main 之间的 commit 列表。

#### 新增 `POST /api/version/update`

执行 `git pull` 更新代码，成功后返回新版本信息。

**安全条件**：只在 `dirty == False` 时允许 pull

### 前端改动

#### `AppShell.vue` 版本 badge

- 红点条件从 `versionInfo.dirty` → `versionInfo.has_update`
- badge 文本：`v0.7.8` → `v0.7.8 (N behind)` 或 `v0.7.8 ✓`
- tooltip 显示更新状态
- 每 5 分钟轮询检查

#### 弹窗改造

现有 changelog modal 改为"版本更新"弹窗：
- 有更新时：显示待拉取的 commits + "一键更新"按钮
- 无更新时：显示已是最新

### 接口定义

**`client.ts`** 新增：
```ts
export interface VersionInfo {
  version: string; commit: string; branch: string; dirty: boolean; display: string;
  has_update: boolean;
  behind_count: number;
}
export async function updateVersion(): Promise<{success: boolean; version: string; message: string}>
export async function getRemoteChangelog(): Promise<{commits: ChangelogCommit[]}>
```
