# 均值回归反向模式讨论

> 2026-06-17 讨论记录
> 议题：价格围绕均价线螺旋运动的实战意义 / 现有策略是趋势型还是回归型 / 反向模式的设计方案

---

## 一、核心洞察：价格围绕均价线螺旋运动

### 1.1 原始观察

> "我发现股价是围绕均价线螺旋前进的。离开均价线远了，就要回来。离开多远，回来的拉力就多强。"

这个观察与经典技术分析的**均值回归（Mean Reversion）**理论一致：
- 价格有向长期均值（均线）靠拢的倾向
- 偏离越大，回归力越强（"橡皮筋"效应）
- 在**震荡市**中尤其成立

### 1.2 但要警惕的盲区

均值回归不是铁律，有两个反例：
- **强趋势市**：2024-2025 金价从 2000 涨到 3500，单边 75%，任何"高位开空"都会被反复打止损
- **"螺旋"不是圆周运动**：实际是"阶梯 + 平台"，每走一段会盘整再走

### 1.3 关键变量：偏离用绝对点数还是 ATR？

| 度量 | 适用 | 风险 |
|------|------|------|
| 绝对点数（如 $10） | 低波动品种 | 高波动时太宽松 |
| **ATR 倍数（推荐）** | **通用** | **需先计算 ATR** |

阈值建议：
- 偏离 < 1 ATR：正常波动，**不视为回归机会**
- 偏离 1-1.5 ATR：轻度回归机会
- 偏离 1.5-2.5 ATR：强回归机会（**最优反向区**）
- 偏离 > 2.5 ATR：极端行情，可能是新趋势起点，**慎用反向**

## 二、关键策略升级思路：不是禁止，是反向

### 2.1 第一反应 vs 第二反应

> "我们的想法不一样。我觉得不是要禁止他。而是要让他在那个位置考虑反向的订单。就是多变成空，空变成多。这样不是赚钱了么"

**第一反应**（在 `strategies/base.py` 已实现）：位置门禁 → **禁止** 极端位置的信号
**第二反应**（用户的洞察）：极端位置 → **反向**（BUY→SELL，SELL→BUY），抓回归

### 2.2 当前 3 单的反向回算

> 这是事后诸葛，但说明：**在震荡市中，回归型信号开在极端位置就是亏钱**。

### 2.3 反向模式的核心优势

- 抓"橡皮筋"回归的 alpha（震荡市主战场）
- 与趋势策略形成对冲（多策略多市场状态）
- 风控优势：反向单的 SL 与趋势单相反方向放置，**总体账户波动率降低**

### 2.4 反向模式的核心风险

- **强趋势市会被反复打止损**——必须先判断市场状态
- 反向单的 SL 通常需要**更宽**（因为逆势入场）
- 不要在趋势刚启动时反向（如 EMA 金叉后立即开空）

## 三、市场状态检测（Regime Detection）

### 3.1 为什么必须做状态检测

- **震荡市**（ADX < 20）→ 反向模式赚钱
- **趋势市**（ADX > 25）→ 顺势模式赚钱，反向模式爆仓
- **过渡区**（20-25）→ 减仓或观望

### 3.2 双重判定指标

```python

    """ADX + BB 宽度双重判定"""
    # ADX：趋势强度
    # BB width：波动幅度
    # 任一指标显示强趋势 → 趋势市
    # 两者都低 → 震荡市
    # 其余 → 过渡

```

**判定规则**：

| ADX | BB 宽度 | 状态 | 推荐模式 |
|-----|---------|------|----------|
| < 20 | < 2.5% | **震荡市** | **反向模式启用** |
| > 25 | > 4% | **趋势市** | 顺势模式 |
| 其他 | 其他 | 过渡 | 减仓或观望 |

### 3.3 简化版 ADX 计算（性能考虑）

不需要严格 Wilder ADX，可用近似：

```python
# 这个 proxy 在 0-1 之间，趋势强时接近 1
```

### 5.2 阶段二：代码实现（回测通过后）

**Step 1：状态检测**（`strategies/base.py`）

```python
def _detect_regime(self) -> str:
    """ADX + BB 宽度判断震荡/趋势"""
    closes = [c.close for c in self.candles[-30:]]
    high = [c.high for c in self.candles[-30:]]
    low = [c.low for c in self.candles[-30:]]

    # BB 宽度
    sma20 = sum(closes[-20:]) / 20
    std20 = (sum((c-sma20)**2 for c in closes[-20:]) / 20) ** 0.5
    bb_width = (2 * std20) / sma20

    # 简化 ADX
    tr = sum(high[i] - low[i] for i in range(-14, 0))
    adx_proxy = tr / (max(high[-14:]) - min(low[-14:])) if max(high[-14:]) > min(low[-14:]) else 0

    if adx_proxy < 0.5 and bb_width < 0.025:
        return 'ranging'
    elif adx_proxy > 0.7:
        return 'trending'
    return 'transition'
```

**Step 2：反向门禁**（`_apply_kline_filters` 末尾）

```python
# ── ④ 反向模式（仅震荡市 + 回归型策略） ──
if self.reverse_mode_enabled:
    regime = self._detect_regime()
    if regime == 'ranging' and self.name in self.reverse_strategy_whitelist:
        ema21 = self._calc_ema_closes(21)
        atr = self._calc_atr()
        if ema21 and atr:
            dist_atr = abs(close - ema21) / atr
            if signal == OrderType.BUY and close > ema21 and dist_atr > self.reverse_atr_threshold:
                signal = OrderType.SELL
                factors_long.append(f"REVERSE→SELL({dist_atr:.1f}σ)")
                logger.info(f"[{self.name}] 反向: 高于均价线 {dist_atr:.1f}σ，BUY→SELL")
            elif signal == OrderType.SELL and close < ema21 and dist_atr > self.reverse_atr_threshold:
                signal = OrderType.BUY
                factors_short.append(f"REVERSE→BUY({dist_atr:.1f}σ)")
                logger.info(f"[{self.name}] 反向: 低于均价线 {dist_atr:.1f}σ，SELL→BUY")
```

## 六、与现有功能的关系

### 6.1 与"位置门禁"的关系

`strategies/base.py:65-93` 已有"位置门禁"（POS-GATE），但：
- 用 high-low 范围（0-1 位置），不是 MA 距离
- 默认 0.90 阈值（价格到 90% 才禁）—— **太宽松**
- 仅禁止，不反向

**建议**：保留位置门禁作为**粗筛**，新增 MA 距离门禁（**带反向逻辑**）作为**细筛**。

### 6.2 与 sanqing_h1 v7 现有逆势因子的关系

sanqing v7 已有：
- RSI-OB/OS（+2，逆势）
- PRICE-HIGH/LOW（+1，逆势）
- 逆势阈值 = 7 分（高于顺势 5 分）

**结论**：v7 的做法是"策略内谨慎反向"，是合理设计。**不建议**外层反向逻辑覆盖它，而是降低现有因子的反向门禁。

### 6.3 与 News-Bias 阻塞的关系

`bias_state.py` 提供 bearish/bullish 阻塞（`block_long_when_bias_bearish` 等）。

**关系**：
- 反向模式 + bearish bias → **双重反向**（应禁用避免过度反向）
- 建议：bias=bullish 时不要反向 BUY 信号（BUY 顺势更稳）

## 七、风险与注意事项

### 7.1 已知风险

1. **趋势市反向 = 爆仓**（最大风险）
   - 缓解：regime 检测（ADX + BB width）
   - 缓解：反向策略白名单（不覆盖 gold_auto + mtf）
   - 缓解：反向单 SL 1.5x ATR（更宽）

2. **状态判断的滞后性**
   - ADX/BB 都有滞后，趋势启动后可能 5-10 根 K 线才识别
   - 缓解：先小仓位试运行，观察 1-2 周

3. **震荡市被假突破打止损**
   - 震荡市假突破常见，SL 太窄会被扫
   - 缓解：SL 1.5x ATR（更宽）

4. **回测过拟合**
   - 单一品种、单一时间段可能不普适
   - 缓解：跨品种验证（先 XAUUSD，再试 EURUSD、GBPUSD）

### 7.2 监控指标

上线后需重点监控：
- 反向单的胜率（应 > 55%）
- 反向单的平均持仓时间（应 < 顺势单）
- 反向单触发 SL 的频率（应 < 30%）
- 总账户最大回撤（应 < 15%）
