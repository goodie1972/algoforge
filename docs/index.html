Features

Core Features

Full-chain coverage: from data collection to strategy execution, from risk control to monitoring

⚡

Multi-Strategy Parallel

25+ strategies run simultaneously with independent magic numbers & risk states. Auto-scans strategies/ the strategies/ directory for new strategies — zero-config registration.

🏗️

Three-Rail Architecture

DataFactory (data + indicators) → Strategist (signal scoring) → Athlete (tick verification) — three independent layers, clear separation of duties.

🛡️

Complete Risk Control

Profit-drawdown take-profit + ATR trailing stop + ATR hard stop. GateManager / RiskManager / TradeManager — three-layer protection.

📊

Data-Driven

DataFactory computes 26 TA-Lib indicators, F043 MT4 values preferred, shared cross-strategy cache with zero redundant computation.

📝

Paper Trading

Full simulation of entries/exits, strategy-rule-based closes, real-price PnL — fully validated before going live.

🔄

Self-Healing Monitor

Auto health check every 5 minutes, auto-restart on crash / bridge disconnect, real-time WebSocket push, full log tracking.
