AlgoForge

XAUUSD 黄金量化交易系统
Algorithmic + Forge = 算法锻造工坊 — 多策略并行、多层风控、实时 Web 监控的黄金自动化交易平台
Python 3.10+ FastAPI Vue 3 MetaTrader 4 SQLite v2.3.0

⚡ 核心特性

多策略并行

25+ 个策略同时运行，独立 Magic Number 和风控状态。自动扫描发现新策略，零配置注册。

三轨架构

DataFactory（数据）→ 策略员（信号）→ Athlete（开仓），三层分离，职责清晰。

完整风控

利润回撤止盈 + ATR 移动止盈 + ATR 硬止损。GateManager / RiskManager / TradeManager 多层防护。

数据驱动

DataFactory 统一计算 26 个 TA-Lib 指标，F043 MT4 值优先，跨策略共享缓存。

纸面测试

信号全量模拟入场 + 出场，按策略规则模拟平仓，真实成交价计算盈亏。

自修复监控

5 分钟自动检查引擎状态，崩溃 / 桥接断连自动重启，实时 Web 仪表盘。
