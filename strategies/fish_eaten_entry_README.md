# fish_eaten_entry.py — 衰竭打分模块

**被 `fish_eaten_v3.py` 调用。** 是 fish_eaten v3.1 入场打分制的纯函数实现。

## 为什么独立成模块

- **实盘/回测共用同一份打分逻辑**——避免两套代码漂移出 bug
- **纯函数 + 可观测**：给定一段指标序列，返回打分明细（哪几项通过、哪几项不及格），便于回测日志调试与策略可解释性
- **可移植**：未来移植到其他回归策略或研究项目时，整模块拷走即可

## 接口

### `EntryParams`(dataclass)
打分参数。默认值是回测冠军：
```python
adx_min = 22.0           # ADX 下界
adx_max = 60.0           # ADX 上界（>60 情绪高潮，反而不入）
di_diff_min = 5.0        # DI 差下界
score_min = 4            # 总分阈值（满分 10）
div_lookback = 8         # 背离回看根数
require_pierce = False   # 插针收回是否做硬门禁
```

### `score_entry(side, ctx, p) -> dict`
| 参数 | 含义 |
| --- | --- |
| `side` | `"LONG"` / `"SHORT"` |
| `ctx` | 单 bar 上下文（dict，键见源码注释） |
| `p` | `EntryParams` 实例 |

返回 `dict`：
```python
{
    "pass": bool,           # True = 入场
    "score": int,           # 总分
    "max": int,             # 最大分（=10）
    "reasons": list[str],   # 通过的信号名
    "side": "LONG"/"SHORT",
}
```

### `seq_at(sides, key, n)`
按 K 线时间回查历史序列（`get_indicator_series` 的便捷封装）。供策略在每根新 K 线触发时增量读取，避免每个分数项都单独查 DB。

## 6 道信号的内在逻辑

| # | 信号 | 解决的"挨打原因" |
| --- | --- | --- |
| ① | ADX 掉头 | v2 只问"ADX > 22"——趋势方向存在但已无动能，仍入场。补"ADX 掉头"避免趋势衰竭中段入场 |
| ② | DI 收敛 | v2 只问"∣DI∣ > 5"——趋势方向明确但仍在加速，仍入场。补"DI 收敛"避免情绪高潮期入场 |
| ③ | 带宽收缩 | 替代 v2 的 `bb_mid_dir == "down"`——前者描述能量衰减，后者描述趋势方向，语义错位 |
| ④ | 插针收回 | 替代 v2 的 `close ≤ 下轨+5`——前者描述反转形态，后者描述 band walk（趋势延续形态），误把延续当衰竭 |
| ⑤ | RSI 离开超卖 | 替代 v2 的"瞬时极端"——前者描述"已上升离开"，后者描述"刚跌破"，前者可靠性高一个量级 |
| ⑥ | 背离 | v2 没有——直接补缺，价格新低但 RSI 不新低是经典反转信号 |
