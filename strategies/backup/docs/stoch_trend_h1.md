## 评分因子

### BUY（做多）
| # | 因子 | 得分 | 说明 |
|:-:|:----|:----:|:----|
| ① | ADX 趋势确认 | 必要条件 | ADX > 25 趋势市 |
| ② | Stoch 超卖金叉 | 必要条件 | H1 Stoch(21,5,3) K<20 + 金叉 |
| ③ | EMA21 上方 | 必要条件 | close > EMA21 |
| ④ | DI 方向 | 必要条件 | +DI > -DI |
| ⑤ | H4 趋势对齐 | 必要条件 | H4 close > EMA21（上行） |
| ⑥ | M15 精确入场 | 确认条件 | M15 Stoch(14,3,3) K<30 |

### SELL（做空）
| # | 因子 | 得分 | 说明 |
|:-:|:----|:----:|:----|
| ① | ADX 趋势确认 | 必要条件 | ADX > 25 趋势市 |
| ② | Stoch 超买死叉 | 必要条件 | H1 Stoch(21,5,3) K>80 + 死叉 |
| ③ | EMA21 下方 | 必要条件 | close < EMA21 |
| ④ | DI 方向 | 必要条件 | -DI > +DI |
| ⑤ | H4 趋势对齐 | 必要条件 | H4 close < EMA21（下行） |
| ⑥ | M15 精确入场 | 确认条件 | M15 Stoch(14,3,3) K>70 |

**判决规则：** AND 逻辑——所有条件必须满足。H4/M15 桥接加载失败时自动跳过对应过滤。

## 出场逻辑

| # | 条件 | 说明 |
|:-:|:----|:----|
| ① | 硬止损 | 亏损超过 2.0 ATR |
| ② | ATR 追踪止盈 | 峰值回撤超过 1.5 ATR |
| ③ | 利润回撤止盈 | 峰值利润回撤 N%（ADX>25 放宽至 50%） |
| ④ | 保本出场 | 走过 ≥0.3ATR 盈利后回到成本附近 |
| ⑤ | ADX<20 | 趋势衰竭出场 |
| ⑥ | DI 反转 | BUY 持仓 -DI>+DI 或 SELL 持仓 +DI>-DI 时出场 |

## 特别规则

- XAUUSD 专用参数：H1 Stoch(21,5,3) 减少黄金趋势中的假信号
- ADX ≤ 25：震荡市，Stoch 信号不可靠，不交易
- 多周期架构：H4 趋势方向 + H1 信号 + M15 精确入场
- 数据源：全部指标从 DataFactory TA-Lib 读取
