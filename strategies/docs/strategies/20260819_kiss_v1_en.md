**Timeframe:** H1 (H4 MACD for trend direction)

## Entry Logic
### Long Entry
| # | Condition | Description |
| --- | --- | --- |
| 1 | Price pullback ≤ 60SMA | Price pulls back to SMA60 from above |
| 2 | H4 MACD > 0 | Higher timeframe trend up |
| 3 | Price within 5×ATR range | Avoid extreme deviation |
### Short Entry
| # | Condition | Description |
| --- | --- | --- |
| 1 | Price bounce ≥ 60SMA | Price bounces to SMA60 from below |
| 2 | H4 MACD < 0 | Higher timeframe trend down |
| 3 | Price within 5×ATR range | Avoid extreme deviation |
## Exit Logic
| # | Condition | Description |
| --- | --- | --- |
| ① | EMA20 direction reversal | Long: EMA20 turns down; Short: EMA20 turns up |
| ② | ATR Hard Stop | 2.0×ATR loss stop |
