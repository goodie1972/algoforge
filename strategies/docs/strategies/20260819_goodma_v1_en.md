**Timeframe:** H1

## Entry Logic
### Long Entry
| # | Condition | Description |
| --- | --- | --- |
| 1 | Price pullback ≤ 60SMA | Price pulls back to SMA60 from above |
| 2 | 60SMA direction up | MA in bullish alignment |
### Short Entry
| # | Condition | Description |
| --- | --- | --- |
| 1 | Price bounce ≥ 60SMA | Price bounces to SMA60 from below |
| 2 | 60SMA direction down | MA in bearish alignment |
## Exit Logic
| # | Condition | Description |
| --- | --- | --- |
| ① | EMA20 direction reversal | Long: EMA20 turns down; Short: EMA20 turns up |
| ② | ATR Hard Stop | 2.0×ATR loss stop |
## Parameter Reference
| Parameter | Value | Description |
| --- | --- | --- |
| TIMEFRAME | H1 | Primary running timeframe |
| DIR_MA_PERIOD | 60 | Direction MA (SMA) period |
| ENTRY_MA_PERIOD | 60 | Entry MA period (shared with direction MA) |
| MIN_TREND_STRENGTH | 0.5 | Minimum MA gap (dollars); skip if trend strength insufficient |
| MIN_ENTRY_DISTANCE | 0.3 | Minimum entry distance (dollars), allowed deviation for pullback/bounce |
| FIXED_LOTS | 0.01 | Fixed lot size |
| MAX_SLIPPAGE | 30 | Max slippage |
## Risk Control
- Stop loss: max(2.0×ATR, $15); take profit: max(3.5×ATR, $35) (`get_dynamic_sl_tp`)
- Fixed 0.01 lots, max slippage 30; direction reversals are exited uniformly by the engine via fixed SL/TP
## Data Source
- Dependencies: `close`, `sma_60`, `ema_20`, `atr`
