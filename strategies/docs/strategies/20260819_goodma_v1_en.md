## Entry Logic
### Long Entry
| # | Condition | Description |
| --- | --- | --- |
| 1 | Price pullback ≤ 60SMA | Price pulls back to SMA60 from above |
| 2 | 60SMA direction up | MA in bullish alignment |
### Short Entry
| # | Condition | Description |
| --- | --- | --- |
| 1 | Price bounce ≥ 60SMA | Price bounces to SMA60 from below |
| 2 | 60SMA direction down | MA in bearish alignment |
## Exit Logic
| # | Condition | Description |
| --- | --- | --- |
| ① | EMA20 direction reversal | Long: EMA20 turns down; Short: EMA20 turns up |
| ② | ATR Hard Stop | 2.0×ATR loss stop |

- Dependencies: `close`, `sma_60`, `ema_20`, `atr`
