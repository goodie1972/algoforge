---

**适用周期：** H1

## 入场逻辑
### 做多
| # | 条件 | 说明 |
| --- | --- | --- |
| 1 | 价格回踩 ≤ 60SMA | 价格从上方回踩至 SMA60 附近 |
| 2 | 60SMA 方向向上 | 均线呈多头排列 |
### 做空
| # | 条件 | 说明 |
| --- | --- | --- |
| 1 | 价格反弹 ≥ 60SMA | 价格从下方反弹至 SMA60 附近 |
| 2 | 60SMA 方向向下 | 均线呈空头排列 |
## 出场逻辑
| # | 条件 | 说明 |
| --- | --- | --- |
| ① | EMA20 方向反转 | 多单：EMA20 向下；空单：EMA20 向上 |
| ② | ATR 硬止损 | 2.0×ATR 亏损止损 |
## 参数说明
| 参数 | 取值 | 说明 |
| --- | --- | --- |
| TIMEFRAME | H1 | 主运行周期 |
| DIR_MA_PERIOD | 60 | 方向均线（SMA）周期 |
| ENTRY_MA_PERIOD | 60 | 入场均线周期（与方向共用） |
| MIN_TREND_STRENGTH | 0.5 | 最小均线间距（美元），低于此值趋势强度不足跳过 |
| MIN_ENTRY_DISTANCE | 0.3 | 最小入场距离（美元），价格回踩/反弹允许偏离 |
| FIXED_LOTS | 0.01 | 固定手数 |
| MAX_SLIPPAGE | 30 | 最大滑点 |
## 风控
- 止损：max(2.0×ATR, $15)；止盈：max(3.5×ATR, $35)（`get_dynamic_sl_tp`）
- 固定 0.01 手、最大滑点 30；方向反转由引擎依据固定 SL/TP 统一出场
## 数据源
- 依赖指标：`close`, `sma_60`, `ema_20`, `atr`
