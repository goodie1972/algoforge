# XAUUSD Web Dashboard — 开发计划

## 核心原则

不修改现有任何文件。整个 Web 仪表盘放在独立目录 `dashboard/` 下，通过 `sys.path` 引用现有核心模块。和原 `main.py` 互不干扰。

## 实施顺序

### 第 1 步：后端基础设施
- config_service.py — JSON 配置读写
- engine_runner.py — 后台线程启动引擎
- web_manager.py — WebSocket 连接管理

### 第 2 步：REST API + FastAPI 主入口
- routes/engine, account, positions, config, market, logs
- backend/main.py — FastAPI 整合 + CORS + 生命周期

### 第 3 步：Vue 前端
- Vite + Vue 3 + TS 脚手架
- Pinia 存储 + API 客户端 + WebSocket
- 组件：布局、通用、仪表板、配置

### 第 4 步：联调
- 端到端测试

## API 端点

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | /api/engine/status | 引擎状态 |
| POST | /api/engine/start | 启动引擎 |
| POST | /api/engine/stop | 停止引擎 |
| GET | /api/account | 账户信息 |
| GET | /api/positions | 持仓列表 |
| POST | /api/positions/{id}/close | 平仓 |
| POST | /api/positions/{id}/modify | 改 SL/TP |
| GET | /api/config | 获取配置 |
| POST | /api/config | 更新配置 |
| GET | /api/market/price | 买卖价 |
| GET | /api/market/candles | K 线 |
| GET | /api/logs | 日志 |
| WS | /ws | WebSocket 推送 |
