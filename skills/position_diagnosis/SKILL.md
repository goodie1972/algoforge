# 持仓诊断 Skill

基于当前持仓的入场价、浮盈、止损位和市场环境，进行持仓健康度评估。

## 触发条件

当满足以下任一条件时触发本 Skill：

1. 用户明确请求持仓诊断、持仓分析、持仓健康度评估
2. 用户询问"要不要平仓"、"止盈止损怎么设"、"移动止损"等操作性问题
3. 用户询问当前浮盈/浮亏状况
4. 系统检测到有活跃持仓，且用户请求交易相关建议

**不触发的场景**：用户无持仓时询问市场方向（应触发 `market_analysis`）、用户询问系统整体风险（应触发 `risk_check`）、用户仅查询持仓列表（直接读取 bridge 数据即可）。

## 执行流程

### Step 1: 获取当前持仓数据

通过 `core.bridge` 的 `get_positions(symbol="XAUUSD")` 获取所有活跃持仓，每个持仓包含：
- `ticket`: 订单号
- `order_type`: OP_BUY / OP_SELL
- `volume`: 手数
- `open_price`: 入场价
- `current_price`: 当前价
- `stop_loss`: 止损位
- `take_profit`: 止盈位
- `profit`: 浮动盈亏
- `swap` + `commission`: 附加成本

同时通过 `get_tick_price("XAUUSD")` 获取最新 bid/ask 价格。

### Step 2: 计算持仓健康指标

对每个持仓计算以下指标：

| 指标 | 计算方式 | 健康标准 |
|------|----------|----------|
| 浮盈比例 | `(current - entry) / entry × 100` (BUY) 或反向 | > 0 为盈利 |
| 止损距离 | `abs(current - stop_loss)` 换算为点数 | > 1× ATR 为安全 |
| 止盈距离 | `abs(take_profit - current)` 换算为点数 | > 0 且合理 |
| 风险回报比 | 潜在盈利 / 潜在亏损 | ≥ 1.5 为合理 |
| 趋势匹配 | 持仓方向 vs 当前 EMA20/50 排列 | 同向为健康 |

通过 `indicators.calc_atr()` 获取 ATR 值作为波动率参考。

### Step 3: 趋势匹配分析

1. 获取 H1 周期的 `calc_ema(closes, 20)` 和 `calc_ema(closes, 50)` 判断主趋势方向
2. 获取 M30 周期的 RSI `calc_rsi(closes, 14)` 判断短期动量
3. 评估持仓方向是否与当前趋势一致
4. 若反向持仓，评估是否需要调整

### Step 4: 生成操作建议

根据诊断结果，为每个持仓给出明确建议：

| 状态 | 建议 |
|------|------|
| 盈利 + 趋势一致 + 止损安全 | **持有** — 维持当前止损 |
| 盈利 + 趋势一致 + 止损过近 | **移动止损** — 建议移至 X 位置 |
| 盈利 + 趋势出现反转信号 | **部分止盈** — 建议止盈 X%，剩余移动止损 |
| 亏损 + 趋势仍一致 | **持有观察** — 关注止损位 |
| 亏损 + 趋势反转 + 接近止损 | **减仓/平仓** — 建议立即处理 |
| 亏损 + 超出合理亏损范围 | **止损出场** — 建议立即平仓 |

## 输出契约

诊断报告必须包含以下结构化段落：

```
## 持仓诊断报告

**时间**: YYYY-MM-DD HH:MM UTC
**当前价格**: Bid $XXXX.XX / Ask $XXXX.XX
**ATR(14)**: $XX.XX

### 持仓概览
| Ticket | 方向 | 手数 | 入场价 | 当前价 | 浮盈/亏 | 止损 | 止盈 |
|--------|------|------|--------|--------|---------|------|------|
| #XXXX  | BUY  | 0.01 | $XXXX  | $XXXX  | $XX.XX  | $XXXX| $XXXX|

### 逐笔诊断

#### Ticket #XXXX
- **浮盈比例**: X.X%
- **止损距离**: XX 点 (X.X × ATR)
- **趋势匹配**: 是/否 — [说明]
- **风险回报比**: X.X
- **建议**: [持有/减仓/移动止损/平仓] — [具体操作和目标价位]

### 综合建议
- [整体持仓策略建议]
- [需要立即关注的事项]
```

## 验证步骤

完成诊断后，逐项检查：

1. **完整性**：所有活跃持仓均已诊断，无遗漏
2. **数据准确**：浮盈/亏计算与 bridge 返回的 profit 字段一致
3. **止损评估**：每个持仓的止损距离已用 ATR 倍数衡量
4. **趋势对照**：已获取 H1/M30 指标数据并与持仓方向对比
5. **操作明确**：每笔建议包含具体操作和价位（非模糊建议）
6. **格式合规**：输出符合上述输出契约的 Markdown 结构
