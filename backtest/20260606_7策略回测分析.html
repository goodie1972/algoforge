五、多周期分析结论

1. H1 最优周期 — 多数策略在 H1 上表现最好 (8645 根 / 2.5 年数据)。H1 平衡了信号频率与趋势持续性, 是黄金回测首选周期。

2. ML-Score & GoldTraderEA H1 扛鼎 — ML-Score (+39.51%, 274 笔) 和 GoldTraderEA (+24.92%, 123 笔) 在 H1 上统计量充足、回撤可控。但两者在 H4 均出现亏损, 提示策略存在最佳时间窗口, 不可跨周期混用。

3. ORB 三周期一直盈利 — 唯一在三周期均盈利且盈亏比稳定的策略 (4~11 笔)。信号虽少但胜在一致性, 适合作为辅助过滤器使用。

4. Grid H4 逆袭 — Grid 在 M30 (-7.17%) 和 H1 (+1.54%) 表现不佳, 但在 H4 (+15.03%) 大放异彩。大周期网格间距更匹配黄金波动节奏。

5. M30 数据短、参考价值有限 — 仅 2.5 个月窗口无法支持统计结论, M30 回测更多反映近期行情特征。

6. H4 逆势策略集体崩溃 — RSI-MR (-8.29%)、SMC-ICT (-7.39%)、ML-Score (-13.11%) 在 H4 均大幅亏损。逆势逻辑在大周期上风险陡增。

核心建议: 以 H1 为主周期部署 ML-Score 或 GoldTraderEA, 用 ORB 做辅助过滤, Grid H4 可做单独模块但需严密风控。
