# XAUUSD 手动策略模拟系统

## 策略池

### 策略1: EMA CROSS (H1) — 趋势跟随
- EMA9上穿EMA21 → 开多
- EMA9下穿EMA21 → 开空
- 反向交叉平仓

### 策略2: RSI REV (M30) — 均值回归+趋势过滤
- H1 EMA方向为趋势基准
- RSI<30 且趋势向上 → 开多
- RSI>70 且趋势向下 → 开空
- RSI回到40-60区间平仓

### 策略3: BB SQUEEZE (M30) — 布林带突破
- BB带宽收缩到近20根最低值 → 挤仓预警
- K线收盘突破上轨 → 开多
- K线收盘突破下轨 → 开空
- 对侧轨道或反向突破平仓

### 策略4: ADX RIDER (H1) — 强趋势骑乘
- ADX>25且DI+>DI- → 开多
- ADX>25且DI->DI+ → 开空
- ADX<20或DI交叉平仓

## 模拟参数
- 初始资金: $10,000
- 每笔开仓: 0.1手 (固定)
- 止损: ATR×2
- 止盈: ATR×4
